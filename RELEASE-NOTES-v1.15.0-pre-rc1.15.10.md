# MediaClean 1.15.0 — PRE-RC1.15.10 (Windows x64)

## Français

**Première préversion de test** de MediaClean pour Windows 64 bits.

- Identification des films avec TMDB et des séries avec TVmaze.
- Nettoyage des noms de fichiers et rangement facultatif.
- Traitement partiel des fichiers sûrs, contrôle des collisions et possibilité d'annuler les opérations.
- Gestion facultative des versions multiples d'un même film.
- **419 tests de régression réussis** lors de la compilation Windows sur GitHub Actions du 4 novembre 2026.

**Téléchargement :** archive autonome Windows x64 (runtime .NET inclus). Décompressez le ZIP et lancez `MediaClean.exe`.

**Attention :** cette préversion doit encore être validée manuellement sur Windows et avec des copies de fichiers vidéo. Évitez de la tester d'emblée sur votre vidéothèque principale.

**SmartScreen / « Éditeur inconnu » :** programme non signé numériquement. Téléchargez uniquement depuis la Release officielle, vérifiez l'empreinte SHA-256 fournie et conservez vos protections Windows actives.

MediaClean est un projet personnel **gratuit**, avec un don entièrement facultatif depuis l'application. **Interface française uniquement** à ce jour.

## English

**First test pre-release** of MediaClean for 64-bit Windows.

- Movie identification via TMDB and TV series identification via TVmaze.
- Filename cleanup and optional organization.
- Partial application of safe changes, conflict checks and Undo support.
- Optional handling of multiple versions of the same film.
- **419 automated regression tests passed** in the Windows GitHub Actions build on November 4, 2026.

**Download:** self-contained Windows x64 ZIP (includes the .NET runtime). Extract it and run `MediaClean.exe`.

**Important:** this pre-release still requires manual UI validation; start with copies of your media files, not your main library.

**SmartScreen / “Unknown publisher”:** the application is not digitally signed. Download only from this official Release, verify the supplied SHA-256 checksum, and keep Windows security protections enabled.

MediaClean is a **free personal hobby project**. Optional donations are available within the application. **French UI only** for now.
